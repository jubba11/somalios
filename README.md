# SomaliOS - Enterprise Operating System for Somali SMEs

SomaliOS is a multi-tenant business operating system designed for Somali small and medium-sized enterprises.

## Tech Stack and Architecture
- Architecture: Modular Monolith
- Backend: PHP 8.5 / Laravel REST JSON API
- Frontend: React / Vite
- Database: PostgreSQL 18
- Web Server: Nginx
- Containers: Docker and Docker Compose
- Accounting Engine Currency: USD ONLY

## Directory Structure
- backend/ - Laravel Modular Monolith application
- frontend/ - React Single Page Application
- docker/ - Nginx, PostgreSQL, and runtime container configurations
- docs/ - Architectural specifications, ERDs, and API contracts
- scripts/ - Development, seed, test, and deployment utilities
